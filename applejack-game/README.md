# 苹果嘉儿的丰收节冒险

面向小学三年级的中文二维网页游戏。视觉依据为用户选定的第一张“分苹果关卡”。

## 试玩

`applejack-play.html` 是自包含的试玩文件，内含脚本、图片及字体。设计为下载后用桌面版Chrome或Edge打开，无需联网下载素材。当前已验证通过HTTP打开单文件；测试环境的浏览器策略禁止file://，本机双击启动仍需实际确认。若浏览器限制本地文件，按下方开发运行方式启动。中文朗读依赖浏览器语音能力；不可用时仍可阅读和游玩。

游戏首次进入分苹果关卡。点一颗苹果，再点篮子，也可以拖动。点击篮中苹果或篮子上的计数按钮可以取回；“帮帮我”显示方法，“装好啦”验证平均分。

“返回农场”可进入语文邮局、科学观察、任务选择和基础装饰。数学9关、语文6关、科学6关，共21关。每关首次完成奖励3个苹果，重复完成不重复奖励。完成进度、设置和已购装饰保存在当前浏览器；关卡内未提交的操作不存档。不同浏览器、文件位置或网站地址不会自动共享进度。

## 开发运行

需要Node.js 20.19+或22.12+。

```sh
npm ci
npm run dev
```

打开命令打印的本机地址。`npm run build` 进行类型检查并输出静态网站到 `dist/`；发布时将整个 `dist/` 交给静态托管服务。`npm test` 检查题目规则、异常存档和重复奖励。

`python3 qa/expansion-check.py` 是浏览器验证脚本，需要Python Playwright和Chromium。它在同一进程启动临时静态服务并测试生产构建。脚本中的Chromium路径可按本机安装位置修改。

## 可调整参数与素材

- `src/rules.mjs`：任务数量、篮子数、提示阈值、首次奖励与判定。
- `src/content.ts`：语文便条、科学条件、答案、解释与装饰价格。
- `src/main.tsx`：界面、操作、存档和流程。
- `src/Scene.tsx`：Phaser场景、角色与补间动画。
- `src/style.css`：字体、布局和响应式规则。
- `public/assets/`：通过图像生成制作的独立背景、角色、苹果、篮子、无字UI及中文子集字体。

本版包括基础装饰图标、轻柔合成操作音效、浏览器朗读和四组场景循环背景音乐；尚无角色逐帧行走动作或独立配音。科学场景用简化图示辅助比较，不是植物生长预测。学习记录表示完成情况，不能作为学科掌握程度评估。真实儿童试玩及实机兼容性检查仍可继续开展。

## 场景背景音乐

果园使用 Carefree，友谊邮局使用 Easy Lemon，科学观察使用 Dream Culture，农场使用 Fretless；作者均为 Kevin MacLeod（incompetech.com），按 CC BY 4.0 使用。来源、许可、剪辑记录见 `public/assets/music/README.md` 和 `credits.json`，游戏设置页也提供署名及链接。

四段音乐经过 FFmpeg 解码、循环交叉衔接、统一响度和压缩，长度约38～55秒。首次点击或键盘操作后开始，按场景懒加载，同场景换关不重播，跨场景约0.8秒渐变。默认音乐音量40%，可单独关闭或调节；总静音关闭所有声音。暂停或切后台停止，朗读/结算时降低背景音量。音乐设置单独保存，不改变原有游戏进度格式。设置面板允许试听音乐；浏览器音频不可用时仍可正常游戏。

`python qa/prepare-music.py` 可重制循环（需要FFmpeg、NumPy及网络），原始音乐下载缓存不会提交。`python qa/music-files-check.py` 检查最终音频的长度、响度和循环接点；`python qa/music-check.py` 检查浏览器真实音频输出、完整循环、场景切换、暂停、静音、音量、持久化和下载失败。设置 `GAME_BASE_URL` 可对正式站点执行浏览器检查。

字体为Noto Sans CJK子集（SIL Open Font License）；图标为Phosphor（MIT）。游戏形象为用户指定的《小马宝莉》苹果嘉儿。美术为基于选定参考生成的素材。

## 丰收节扩展版

数学第7～9关为按订单分配；每篮目标不同，可取回调整。农场“布置农场”页签提供3个区域和6件矢量场景装饰，支持预览、取消、购买、免费更换和收起。旧v1存档保留并迁移到独立v2记录，损坏记录不会静默覆盖。页面提供明确的轻音乐开启按钮，触摸和点击都可解锁浏览器音频。

角色已支持在 src/ponyAnimations.ts 配置经审核的精灵表；目前没有生成视频序列帧，仍使用原有角色图与补间反馈。可灵调用尚受Weave/Figma账号关联识别阻塞。
