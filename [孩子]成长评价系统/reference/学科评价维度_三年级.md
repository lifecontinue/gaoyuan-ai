## 二之一、指标 Schema（v2：场景化定义 + 三级判定标准）

> 自 v2 起，`indicators` 由「字符串数组」升级为「对象数组」。每个指标携带**场景化定义（desc）**与**符合 / 较符合 / 不符合 三级可直接观察的判定标准（criteria）**，让家长在家庭场景中能稳定判断，而非凭印象打分。

**指标对象结构**

| 字段 | 类型 | 说明 |
|---|---|---|
| `text` | string | 指标名称（与 v1 文案一致，作为稳定主键载体） |
| `desc` | string | 场景化定义：说明「在什么情境下、看得到什么行为」，替代 v1 的空泛表述 |
| `criteria` | object | `{ "符合": string, "较符合": string, "不符合": string }` 三级判定标准，优先用「是否独立完成 / 是否稳定出现 / 是否需要提醒 / 是否达到基本正确」等可观察证据 |

**前端映射**

- 数据层 `js/data/subjects_p3.js`（由 `reference/学科评价维度_三年级.json` 生成）导出 `SUBJECTS_P3`。
- 领域层 `js/domain/subjects.js` 构建 `SUBJ_COMP_TREES` 时，为每条指标附加稳定主键 `p3-<学科序号>-<主题序号>-<指标序号>`，并透传 `criteria` 字段（向后兼容 v1 字符串指标：`typeof ind === 'string'` 时仅取 `text`）。
- 视图层 `js/ui/detail-views.js` 的 `renderPrimaryIndicator` 在指标卡片中渲染「判定标准（家长可直接对照）」区块，三档分别着色（绿=符合 / 黄=较符合 / 红=不符合）。

**示例（语文·识字与写字）**

```json
{
  "text": "累计识字约2500、会写约1600；遇到生字能借助工具书独立识记",
  "desc": "在家庭阅读或写话中遇到不认识的字，能主动翻字典（音序/部首）查字、看释义，而不是立刻问家长；学过的字能正确书写。",
  "criteria": {
    "符合": "遇到生字大多能自己查字典认读、书写，常用字默写正确率高，写话基本无错别字。",
    "较符合": "能查字典但速度慢、常需提醒；学过的字大致会写，但常有少量错字或同音替代。",
    "不符合": "几乎不主动查字，遇到生字就问；学过的字大量写错或想不起来写。"
  }
}
```

**家长使用口径（与幼儿园阶段一致）**

- 一次不定论，看 1~2 周的稳定表现；习惯类指标不因单次情绪下结论。
- 同一指标连续两次「不符合」才进入重点干预。
- 判定维度优先看：是否独立完成、是否稳定出现、是否需要提醒、是否达到基本正确。

## 四、如何在系统中使用

1. **离线打开** `index.html` → 顶部切换到「🎒 小学」阶段。
2. **测评维度 → 学科维度**：逐门展开 9 个学科卡片，查看主题、内容要求与可评指标；点开任一指标卡片，可见「场景化定义」与「符合 / 较符合 / 不符合 三级判定标准」，家长可直接对照勾选；数学卡片附「学习路径」。
3. **AI 顾问**：进入小学阶段后，欢迎语会自动提示「已备好 9 门学科评价维度」；右下快捷动作新增「📚 三年级学科」一键打开学科维度；「🎯 推荐亲子活动」在小学阶段改为按学科维度给出建议。
4. **家长记录**：可在小学阶段新增观察 / 打卡 / 自评，作为期末综合评价证据（与幼儿园阶段同套机制）。
