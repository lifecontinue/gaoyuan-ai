# 模块 5：迭代与调试入门

> 所属项目：Vibe Coding 分层学习课件（10 模块 · 月度节奏）
> 统一素养锚点：运用自然语言与 AI 协作，把真实想法变成可运行、可展示的数字作品，体现计算思维与数字化创新意识。

## 1. 模块基本信息
- **主题**：迭代与调试 · 看懂 AI 给的代码，说出哪里不对
- **时长**：1 小时集中授课
- **前置模块**：模块 4（已有主页 v0.1）
- **核心活动**：故意给"有 bug 的代码"，教学生用"调试四步法"找出不对
- **产出物**：一份"我改好了"的截图对比（改前/改后）
- **评估方式**：能否说清"我想要 X，实际 Y，我让 AI 改了 Z"

## 2. 素养锚点回指
本模块训练锚点中的**"迭代调试"**与**"批判性审视"**：不盲信 AI，能验证并修正。三层都完成"定位+描述+修复"，①号已知位置、③号自主发现，**调试独立度不同，目标都是"让作品变对"**。

## 3. 学情诊断与分层建议（三通道）
- **通道 A**：模块 4 作品运行稳定性，常报错者留①号。
- **通道 B**：给一段错代码，看能否描述"哪里怪"——能描述进②/③。
- **通道 C**：遇 bug 是否慌/想放弃——配①号"自己圈位置"降挫败感（老师巡课时帮圈第一处，之后学生照做）。
- **本月分层**：据项目 A 进度定层；可流转。

## 4. 三层任务卡
**①号起步卡**
- 任务内容：用"自己圈位置"法练手——把可疑代码段截图圈出来（或复制给 AI），**不依赖老师标行号**（真实生成代码的几行无法预标注）。老师巡课时先帮圈第一处，之后学生照做。
- 开放度：低。
- 支架供给：圈位置示范 + 描述句式（"我想要 X，实际 Y"）。
- 评价标准：圈出可疑段并改好、截图 = 达标。
- 生长点：②号"自己定位"以①号"会圈位置"为起点。

**②号进阶卡**
- 任务内容：给未标注的 bug，自己定位并描述。
- 开放度：中。
- 支架供给：调试四步法清单。
- 评价标准：定位准确 + 描述清楚 = 良好。
- 生长点：③号"修 2 个+解释成因"是②号延伸。

**③号挑战卡**
- 任务内容：自己发现并修复 2 个 bug，且解释成因。
- 开放度：高。
- 支架供给：仅四步法框架。
- 评价标准：修 2 bug + 成因说明 = 优秀。

## 5. 课堂活动设计（1 小时）
| 环节 | 时间 | 内容 |
|---|---|---|
| 导入 | 10min | "AI 也会写错"——演示一个看着对其实错的按钮 |
| 讲解 | 15min | 调试四步法：复现→定位→描述→验证 |
| 实操 | 20min | 分层修 bug，巡课（多偏①号） |
| 展示 | 10min | 展示"改前 vs 改后"截图 |
| 小结 | 5min | "会修，才是真会做" |

## 6. 方法论脚手架
- **调试四步法**（步骤支架）：
  1. 复现：怎么做就会出问题？
  2. 定位：大概哪一步/哪块不对？
  3. 描述：用"我想要 X，实际 Y"告诉 AI。
  4. 验证：改完再跑一遍确认。
- 撤除节点：M5 教 → M8 熟用。

## 7. 微信跟进包
- **月度任务**："在你主页里找一个'不对劲'的地方，用四步法修掉，发对比图。"
- **分层推送**：①号发"标好位置"练习包；②号问"你定位到第几步了？"；③号挑战"找 2 个隐藏 bug。"
- **卡点话术**：英文报错看不懂 → "先别关页面！右键→检查→点 Console→把第一行红字复制给我，我们一起猜它在说什么。"（详见环境准备包第 4 节）

## 8. 评估量规
| 等级 | 表现描述 |
|---|---|
| 达标 | 按标好位置改好 bug 并截图 |
| 良好 | 自主定位未标注 bug + 描述清楚 |
| 优秀 | 发现并修复 2 bug + 解释成因 |
| 卓越 | 修复后能预防同类问题（加检查） |
