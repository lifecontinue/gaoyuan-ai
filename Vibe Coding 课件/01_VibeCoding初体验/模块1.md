# 模块 1：Vibe Coding 初体验

> 所属项目：Vibe Coding 分层学习课件（10 模块 · 月度节奏）
> 统一素养锚点：运用自然语言与 AI 协作，把真实想法变成可运行、可展示的数字作品，体现计算思维与数字化创新意识。

## 1. 模块基本信息
- **主题**：Vibe Coding 是什么 · 第一次让 AI 写出网页
- **时长**：1 小时集中授课
- **前置模块**：无（开课第一月）
- **核心活动**：演示"说话做网页"→ 学生用一句话让 AI 生成"会变色的小按钮"→ 哇塞时刻
- **产出物**：人生第一个 AI 生成网页（截图）
- **评估方式**：课堂观察"能否打开并操作自己的作品"

## 2. 素养锚点回指
本模块是锚点的"入口体验"：学生第一次实践"我说话→AI 写代码→我验收"。三层都达成"生成并操作一个网页"，只是①号用现成提示词、③号自己写一句话——**目标一致，支架不同**。

## 3. 学情诊断与分层建议（三通道）
- **通道 A 知识基础**：开课前趣味问卷（是否用过编程/有无英文基础/打字速度）。无经验者初始入①号。
- **通道 B 认知加工**：开放题"你想让网页做什么？"——能说出具体功能者倾向②/③号。
- **通道 C 动机与效能**：访谈"你觉得编程难吗？"——"怕但想试"≠能力差，照样进①号并配同伴支架。
- **本月分层初判**：全员先发①号体验；课后据完成度与意愿，下月模块 2 调整。

## 4. 三层任务卡
**①号起步卡**
- 任务内容：老师给现成提示词，学生复制运行，截图即可。
- 开放度：低（填空式操作）。
- 支架供给：完整提示词 + 运行步骤图。
- 评价标准：能打开作品并截图 = 达标。
- 生长点：②号的"改一词"建立在①号"能运行"之上。

**②号进阶卡**
- 任务内容：按模板把提示词里"蓝色"改成"红色"再运行。
- 开放度：中（改 1 个参数）。
- 支架供给：半开放提示词（关键词留空）。
- 评价标准：改词后功能正确 + 截图 = 良好。
- 生长点：③号"自己写一句话"是②号的自然延伸。

**③号挑战卡**
- 任务内容：自己写一句话，让按钮"点一下弹出我的名字"。
- 开放度：高（自主表达需求）。
- 支架供给：仅给 R-T-R-E 模板框架。
- 评价标准：自主写出并跑通 = 优秀。
- 生长点：为模块 3 的"提示词四要素"铺垫。

## 5. 课堂活动设计（1 小时）
| 环节 | 时间 | 内容 |
|---|---|---|
| 导入 | 10min | 演示：老师口述"做个会变色的按钮"，AI 当场生成，学生惊呼 |
| 讲解 | 10min | 一句话讲清 Vibe Coding = 我说话、AI 写码、我来验收 |
| 实操 | 25min | 分层发①②③号任务卡，教师巡课（70% 时间偏向①号） |
| 展示 | 10min | 3 名学生演示自己的按钮，全班鼓掌 |
| 小结 | 5min | 点题："今天你已经是会指挥 AI 的创作者了" |

## 6. 方法论脚手架
- 本模块主用**运行步骤图**（视觉支架，实物见 `../脚手架实物/运行步骤图.md`）：打开工具→粘贴→点生成→存 .html→双击看。若环境打不开，先去 `../00_环境准备/环境准备包.md`。
- 撤除节点：本模块给全套；模块 3 起替换为提示词模板。

## 7. 微信跟进包（课后全月）
- **月度任务**："这个月随便玩，用 AI 生成一个你喜欢的小东西（按钮/颜色/一句话），截图发我～"
- **分层推送**：①号附"步骤图"；②号问"你想改哪个词？"；③号挑战"试试用一句话做两个效果"。
- **卡点话术**：环境打不开 → "先别急，去看 `00_环境准备/环境准备包.md` 第 3 节步骤卡，截图你卡在哪一步？我们一起排。"（无电脑学生转纸质任务，见该包第 5 节）

## 8. 评估量规（达标 / 良好 / 优秀 / 卓越）
| 等级 | 表现描述 |
|---|---|
| 达标 | 用现成提示词生成网页，能打开并截图 |
| 良好 | 修改参数后生成，功能正确 |
| 优秀 | 自主写一句话生成，跑通 |
| 卓越 | 自主生成且主动尝试 2 个效果并对比 |
