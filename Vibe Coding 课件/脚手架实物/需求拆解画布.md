# 需求拆解画布（可直接打印 / 填写）

> **用途**：把"我想做个网页 / 小工具"这种模糊想法，变成 AI 能听懂的功能清单。
> **什么时候用**：模块 2 学它；之后模块 4（个人主页）、模块 7（小工具）做项目时一直用。
> **一句话原则**：先想清楚"它要帮人做哪几件事"，再让 AI 写代码。

---

## 📋 空白画布（复印这张填）

```
我的作品名字：________________________

它要帮人做的一件事（用一句话说）：
________________________________________

功能点 1：________________________
  需要什么互动？  □ 点击  □ 输入文字  □ 滑动  □ 自动

功能点 2：________________________
  需要什么互动？  □ 点击  □ 输入文字  □ 滑动  □ 自动

功能点 3：________________________
  需要什么互动？  □ 点击  □ 输入文字  □ 滑动  □ 自动

（写完念一遍：每个功能点，别人照着能做出来吗？）
```

---

## 🌟 示例画布（照这个学）

```
我的作品名字：我的随机点名器

它要帮人做的一件事：上课时公平地随机抽一个同学起来。

功能点 1：页面上显示一个"开始"按钮
  需要什么互动？  ☑ 点击

功能点 2：点一下按钮，屏幕随机跳出一个同学名字
  需要什么互动？  ☑ 点击

功能点 3：再点一下，换另一个人（不重复最好）
  需要什么互动？  ☑ 点击
```

---

## 💡 给①号同学的小提示
- 不会自己想？先抄上面的"示例画布"，把"点名器"换成你想做的东西。
- 功能点写不出 3 个？先写 1 个也行，做出来再说，后面再加。
- 拿不准"互动"选哪个？凡是要点一下的，都勾"点击"。
