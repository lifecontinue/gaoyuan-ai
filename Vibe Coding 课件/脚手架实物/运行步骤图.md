# 运行步骤图（第一次做网页必看）

> **用途**：从"打开工具"到"看到自己的网页"，一步一步照做。
> **打不开环境？** 去看 `../00_环境准备/环境准备包.md`（工具怎么选、怎么登录、怎么看报错）。

---

## 🚶 五步流程图

```
[1 打开工具] → [2 粘贴提示词] → [3 点"生成"] → [4 复制代码存成 .html] → [5 双击用浏览器打开]
```

### 详细每步
1. **打开工具**：在浏览器里打开 AI 对话工具（具体用哪个，看环境准备包）。
2. **粘贴提示词**：把你的提示词（用"提示词四要素"写的）整段复制进去，发给 AI。
3. **点"生成"**：等它吐出代码（通常是一个带 ```html 的代码块）。
4. **复制存成文件**：把 AI 给的代码全选复制 → 新建一个文本文件 → 粘贴 → 存成 `我的网页.html`（**注意后缀是 .html，不是 .txt**）。
5. **双击打开**：在文件夹里双击这个 .html 文件，会用浏览器打开，你就能看到网页了！

---

## ⚠️ 常见卡点（先自查，不行再问老师）
- **找不到"生成"按钮？** → 看环境准备包里的工具截图，确认你打开的是对话工具不是别的应用。
- **打开后是乱码 / 空白？** → 多半是没存成 .html，检查文件名后缀是不是 `.html`。
- **点了没反应？** → 别关页面！用"调试四步法"（见模块 5）：先复现、再定位、描述给 AI、最后验证。
- **出现英文报错？** → 右键页面 → "检查" → "Console" → 复制第一行红字，发给老师或贴进下一条提示词。
