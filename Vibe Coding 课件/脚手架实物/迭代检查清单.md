# 迭代检查清单（改一次，勾一遍）

> **用途**：每次让 AI 改了代码之后，用这 4 个问题确认"真的改好了没有"。
> **什么时候用**：模块 6 开始正式用；模块 8 之后要**自己主动用**（不用老师提醒）。
> **一句话原则**：没在浏览器里打开看过的改动 = 没做完。

---

## ✅ 四问清单（贴在屏幕边 / 抄在笔记本上）

```
每次改完，逐条问自己：

□ 1. 跑起来了吗？      （没在浏览器里打开看 = 没做完）
□ 2. 和我想要的一样吗？ （逐条对"需求拆解画布"的功能点）
□ 3. 哪里不对劲？      （圈出来 / 截图，别无视它）
□ 4. 我让 AI 改了什么？ （用一句话记下来，下次好复盘）
```

---

## 📒 改 bug 记录表（建议每次记一行）

| 日期 | 我想要 X | 实际 Y | 我让 AI 改了什么 | 现在好了吗 |
|---|---|---|---|---|
| | | | | □是 □否 |

> 第一次不会填第 3、4 格很正常——先填"我想要"和"实际"，发给老师帮你补后面两格。

---

## 💡 给①号同学
- 第 1、2 问最简单，先做这两问。
- 不会第 3 问？把页面截图发老师，老师帮你圈出"不对劲"的地方。
- 每改一次，就把 4 个框重新勾一遍，不要一口气改完才看。
