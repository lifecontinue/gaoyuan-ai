# 模块 2：把想法变成"说明书"

> 所属项目：Vibe Coding 分层学习课件（10 模块 · 月度节奏）
> 统一素养锚点：运用自然语言与 AI 协作，把真实想法变成可运行、可展示的数字作品，体现计算思维与数字化创新意识。

## 1. 模块基本信息
- **主题**：需求拆解 · 把"我想做个网页"变成功能清单
- **时长**：1 小时集中授课
- **前置模块**：模块 1（已体验生成网页）
- **核心活动**：用"需求拆解画布"把模糊想法拆成 3 个功能点
- **产出物**：一张写好的拆解画布（想法 → 3 功能点）
- **评估方式**：同伴互评"别人能不能照你的画布做出东西"

## 2. 素养锚点回指
本模块训练锚点中的**"需求拆解"**环节——计算思维的"分解/建模"。三层都产出"可被执行的功能清单"，①号从示例挑、③号加互动标注，**都是分解，深度不同**。

## 3. 学情诊断与分层建议（三通道）
- **通道 A**：回顾模块 1 完成情况，打字/工具熟练度低者留①号。
- **通道 B**：开放题"我想做个能随机点名的网页，分几步？"——能拆 3 步以上进②/③。
- **通道 C**：观察是否仍说"让 AI 全搞定"——若是，配①号+追问支架，引导先想一步。
- **本月分层**：据模块 1 表现定①/②/③；可申流转。

## 4. 三层任务卡
**①号起步卡**
- 任务内容：从老师给的 3 个示例里挑 1 个，照画布填空。
- 开放度：低。
- 支架供给：示例画布 + 填空格式。
- 评价标准：选出示例并填完 = 达标。
- 生长点：②号"自己想"以①号"示例结构"为样板。

**②号进阶卡**
- 任务内容：自己想 1 个小作品，拆出 3 个功能点。
- 开放度：中。
- 支架供给：空白画布 + 提示"先想它要做什么"。
- 评价标准：拆出 3 点且可被他人理解 = 良好。
- 生长点：③号"加互动标注"是②号延伸。

**③号挑战卡**
- 任务内容：拆出 3 功能点 + 每个点标注"需要什么互动"。
- 开放度：高。
- 支架供给：仅画布框架。
- 评价标准：功能点 + 互动标注清晰 = 优秀。

## 5. 课堂活动设计（1 小时）
| 环节 | 时间 | 内容 |
|---|---|---|
| 导入 | 10min | 对比："我想要个好看的网页"（模糊）vs "标题+照片+3 句话"（清晰） |
| 讲解 | 10min | 教拆解画布：想法→3 件事→每件事的互动 |
| 实操 | 25min | 分层写画布，教师巡课 |
| 展示 | 10min | 同桌互换画布，试着"照做"，反馈"我懂了/我没懂" |
| 小结 | 5min | "好提示词的前提，是好拆解" |

## 6. 方法论脚手架
- 本模块主用**需求拆解画布**（语言+结构支架）。
- 撤除节点：M2 示例填 → M4 自想 → M7 加标注。

## 7. 微信跟进包
- **月度任务**："把你上个月的网页想法，用拆解画布写下来，拍照发我。"
- **分层推送**：①号发示例模板；②号问"你的 3 个功能想好了吗？"；③号挑战"每个功能怎么互动？"
- **卡点话术**：想不出功能 → "先别想网页，想'你希望它帮你做什么事？'一件件列。"

## 8. 评估量规
| 等级 | 表现描述 |
|---|---|
| 达标 | 从示例中选 1 个并填完画布 |
| 良好 | 自主想出作品并拆出 3 功能点，他人能懂 |
| 优秀 | 功能点 + 互动标注清晰，可被执行 |
| 卓越 | 拆解有层次（主功能+子功能），且能解释取舍 |
