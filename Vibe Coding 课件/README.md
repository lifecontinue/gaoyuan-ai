# Vibe Coding 分层学习课件 · 项目总纲

> **适用对象**：初中生（或零基础普通学生）
> **总时长**：约 10 小时　**节奏**：每月 1 次集中授课（1 小时）+ 全月微信跟进
> **主线项目**：个人主页 / 小工具应用
> **配套文档**：`outputs/Vibe Coding 分层学习课件框架.md`（完整设计说明，本目录为其落地的项目结构版）

---

## 0. 边界声明（不伪装依据）
- **Vibe Coding（用自然语言指挥 AI 写代码）不在《义务教育课程方案》学科目录内**，本课件将其作为**信息科技课程的课外拓展 / 跨学科实践载体**。
- 全程**锚定《义务教育信息科技课程标准（2022 年版 2025 年修订）》四大核心素养**，已联网核对。

## 2. 统一核心素养目标（锚点 · 三层共同指向 · 绝不拆分降低）
> **学生能运用自然语言与 AI 编程工具协作，将一个真实想法转化为"可运行、可展示的数字作品"，并在"需求拆解 → 迭代调试 → 成果审视"全过程中，体现计算思维（抽象 / 分解 / 建模）与数字化学习与创新意识（自主规划、批判性迭代、个性化创作），同时能反思人机协作的边界。**

三层任务卡（①②③号）**共享此锚点**，差异只发生在：内容复杂度、过程独立度、成果开放度、支架供给量。

## 3. 课程目标分层（知识 / 技能 / 素养）
见 `outputs/Vibe Coding 分层学习课件框架.md` 第 1 章。要点：
- **知识 K1–K5**：说清 Vibe Coding / 识别网页三件套 / 理解提示词=说明书 / 知 AI 工具与边界 / 数字作品礼仪。
- **技能 S1–S5**：写结构化提示词 / 拆 3 功能点 / 跑起来验证 / 调试四步法 / 交付可展示作品。
- **素养 L1–L5**：计算思维萌芽 / 批判审视 AI / 数字化自主习惯 / 人机边界意识 / 原创与责任。

## 4. 整体方法论脚手架库（学生可带走，带撤除节点）
| 脚手架 | 内容 | 撤除节点 |
|---|---|---|
| 提示词四要素 R-T-R-E | 角色/任务/要求/示例 | M3 全套 → M5 留清单 → M7 独立写 |
| 需求拆解画布 | 想法→3 功能点→互动标注 | M2 示例填 → M4 自想 → M7 加标注 |
| 迭代检查清单 | 跑起来?/一样吗?/哪不对?/改了啥? | 全程用，M8 起自主 |
| 调试四步法 | 复现→定位→描述→验证 | M5 教 → M8 熟用 |

> 📁 **实物模板已落地**：提示词四要素（M3）、调试四步法（M5）、作品体检单（M8）的模板在各模块内；**需求拆解画布、迭代检查清单、运行步骤图** 三件已做成可打印 / 可复制的独立文件，见 `脚手架实物/` 目录。环境准备（工具选型 / 步骤卡 / 看报错 / 无电脑降级）见 `00_环境准备/环境准备包.md`。

## 5. AI 素养培养路径（嵌模块，可观察可反馈）
| 节点 | 模块 | 观察成长 | 反馈话术示例 |
|---|---|---|---|
| AI 工具理解 | M1 | 不再说"它自己变的"，改说"我让它…" | "你这次说清是'你让 AI 加了按钮'，这就是驾驭工具。" |
| 提示词思维 | M3 | 提示词越具体，AI 命中率上升 | "你把'做好看'改成'蓝底大标题'，一次就对了。" |
| 结果批判审视 | M5/M8 | 主动验证而非直接交差 | "你点了一遍发现按钮没反应——这种不盲信很宝贵。" |
| 人机协作边界 | M7/M10 | 能说"功能我定，代码 AI 写" | "点名器'要公平'是你定的，AI 只是实现——决策权在你。" |

## 6. 项目驱动设计（双项目 · 各含三层）
- **项目 A 个人主页**（M4–M6、M9）：①兴趣名片 → ②个人主页 → ③创意主页（含深色切换）。
- **项目 B 小工具**（M7–M8）：①鼓励卡 → ②随机点名器 → ③背单词卡（双状态）。
- 生长点：①是②子集，③是②自然延伸；三层都收敛回同一锚点。

## 7. 分层命名与动态流转（保护自尊）
- 不叫"优中差"，叫 **①号起步卡 / ②号进阶卡 / ③号挑战卡**（描述任务难度，不标签人）。
- 每月可流转：完成本卡可申升级；遇困可申降级或领"支援包"。微信按卡推不同任务，不公开排名。
- **设备降级（无电脑学生）**：若家庭仅平板 / 手机，课后任务改为纸上画布 / 写提示词，微信跟进改发想法 / 截图，关键实操集中机房或 1v1 时段。详见 `00_环境准备/环境准备包.md` 第 5 节。设备差异只改变"在哪执行"，不改变"学什么、达成什么"。

## 10. 分层设计自检清单（8 问 · 全项目通用）
1. 三层都对应同一学业质量标尺？→ 是，共用计算思维界定句。
2. 差异在复杂度/支架，不在砍核心概念？→ 是。
3. 拔尖层有挑战、基础层有低门槛？→ 是，①填空式入门，③开放创作。
4. 支架有撤除节点？→ 是，M3→M5→M7 三级撤除。
5. 命名不贴永久标签？→ 是，①②③号任务卡，按月流转。
6. 有动态流转机制？→ 是，升级/降级/支援包。
7. 评价用同一核心标尺？→ 是，Rubric 四等共用。
8. 课标依据真实未伪造？→ 是，已联网核对；学业质量条目未逐字定位处已如实说明。
