# 模块 3：提示词四要素

> 所属项目：Vibe Coding 分层学习课件（10 模块 · 月度节奏）
> 统一素养锚点：运用自然语言与 AI 协作，把真实想法变成可运行、可展示的数字作品，体现计算思维与数字化创新意识。

## 1. 模块基本信息
- **主题**：提示词 = 给 AI 的说明书 · R-T-R-E 四要素
- **时长**：1 小时集中授课
- **前置模块**：模块 2（已会拆解需求）
- **核心活动**：学四要素模板，现场改写一段模糊提示词
- **产出物**：一份自己的提示词模板卡（可贴书桌）
- **评估方式**：前后两次提示词对比，看 AI 命中率变化

## 2. 素养锚点回指
本模块训练锚点中的**"自然语言协作"**能力——把拆解好的需求，用结构化语言交给 AI。三层都产出"可用提示词"，①号填空、③号全开放，**表达自由度不同，目标都是"让 AI 听懂"**。

## 3. 学情诊断与分层建议（三通道）
- **通道 A**：模块 2 画布完成质量，低者留①号。
- **通道 B**：给一段模糊提示词，看能否指出"缺什么"——能指出进②/③。
- **通道 C**：是否怕"写不好被笑"——肯定"提示词是练出来的"，配①号填空降焦虑。
- **本月分层**：据前两月表现定层；可流转。

## 4. 三层任务卡
**①号起步卡**
- 任务内容：填空式模板（句子已搭好，只填关键词）。
- 开放度：低。
- 支架供给：完整 R-T-R-E 句子，仅留空填词。
- 评价标准：填完且 AI 能执行 = 达标。
- 生长点：②号"自己写任务句"以①号句式为样板。

**②号进阶卡**
- 任务内容：半开放，任务句自己写，要求照清单勾选。
- 开放度：中。
- 支架供给：任务句留白 + 要求清单勾选。
- 评价标准：任务句清晰 + 勾选合理 = 良好。
- 生长点：③号"全开放+解释"是②号延伸。

**③号挑战卡**
- 任务内容：全开放自己从零写，并解释"为什么这样写更准"。
- 开放度：高。
- 支架供给：仅模板框架。
- 评价标准：自主写出且解释合理 = 优秀。

## 5. 课堂活动设计（1 小时）
| 环节 | 时间 | 内容 |
|---|---|---|
| 导入 | 10min | 同一需求：模糊句 vs 四要素句，AI 结果对比 |
| 讲解 | 15min | R-T-R-E：角色/任务/要求/示例 |
| 实操 | 20min | 分层写模板卡，教师巡课 |
| 展示 | 10min | 用自己模板卡生成，比谁一次更准 |
| 小结 | 5min | "精确表达 = 好结果" |

## 6. 方法论脚手架
- **提示词四要素 R-T-R-E**（语言支架）：
  ```
  【角色】你是一个帮我做网页的小助手。
  【任务】请做一个______（说清做什么）。
  【要求】1) ______  2) ______  3) ______（列清楚）
  【示例】参考这个样子：______（贴图或描述）
  ```
- 撤除节点：M3 全套 → M5 只留要求清单 → M7 独立写。

## 7. 微信跟进包
- **月度任务**："用四要素模板，改写你之前的一段模糊想法，发我看看。"
- **分层推送**：①号发填空图；②号问"你的任务句怎么写？"；③号挑战"试试不加示例，AI 还能懂吗？"
- **卡点话术**：写不出要求 → "先想'做完后你希望看到什么？'一条条写。"

## 8. 评估量规
| 等级 | 表现描述 |
|---|---|
| 达标 | 填空式模板填完，AI 能执行 |
| 良好 | 任务句自写 + 要求合理勾选 |
| 优秀 | 全开放写出且解释"为什么更准" |
| 卓越 | 能对比两种写法，说明命中率差异 |
