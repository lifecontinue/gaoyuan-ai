# 萨提亚家庭沟通卡片游戏机制与规则

基于萨提亚心理咨询理论和已设计的家庭沟通符号系统，我们开发了一套卡片游戏机制与规则，旨在通过互动体验的方式帮助家庭成员改善沟通、增进理解、提升自我价值感。

## 1. 游戏概述

**游戏名称**：「冰山对话」家庭沟通卡片游戏

**游戏目标**：
- 帮助家庭成员识别自己和他人的沟通姿态
- 促进情绪的觉察和表达
- 探索行为背后的深层动机和需求
- 练习一致性沟通
- 增进家庭成员间的理解和连接

**适用人群**：
- 家庭成员（父母、子女、伴侣等）
- 年龄建议：10岁以上
- 参与人数：2-6人

**游戏时长**：30-60分钟

## 3. 游戏基本规则

### 3.1 游戏准备
1. 将各类卡片分别洗混，正面朝下放置
2. 每位玩家抽取：
   - 1张沟通姿态卡（不展示给其他人）
   - 3张情绪表达卡（可以看，不必展示）
   - 2张资源卡（可以看，不必展示）
3. 将冰山探索卡按层次顺序排列，从上到下放置
4. 场景卡和引导卡放在中央备用

### 3.2 基本玩法
游戏分为三个阶段：觉察、探索和实践。

#### 觉察阶段
1. 抽取一张场景卡，朗读场景
2. 每位玩家根据自己的沟通姿态卡，分享在该场景下可能的反应
3. 其他玩家猜测该玩家的沟通姿态
4. 玩家展示沟通姿态卡，并分享自己的感受

#### 探索阶段
1. 从冰山顶层（行为层）开始，依次抽取冰山探索卡
2. 每位玩家根据卡片上的引导问题，分享自己的想法和感受
3. 当探索到感受层时，玩家可以使用情绪表达卡辅助表达
4. 继续向冰山深层探索，直至渴望层或自我层

#### 实践阶段
1. 每位玩家选择一张资源卡，分享如何运用这一资源
2. 尝试用一致性沟通姿态重新应对场景
3. 其他玩家给予反馈和支持

### 3.3 计分规则（可选）
- 成功识别他人沟通姿态：1分
- 使用情绪表达卡准确表达感受：2分
- 探索到冰山深层（渴望层或自我层）：3分
- 成功运用资源卡：2分
- 展示一致性沟通：3分

## 4. 游戏变体与扩展玩法

### 4.1 "冰山探险"模式
专注于探索个人冰山各层次，适合深度自我探索。
1. 每位玩家抽取一个个人议题
2. 使用冰山探索卡，从行为层逐步向下探索
3. 其他玩家提供支持性问题和反馈
4. 探索完成后，分享洞见和收获

### 4.2 "沟通转化"模式
专注于练习不同沟通姿态之间的转化，尤其是向一致性沟通的转变。
1. 每位玩家抽取两张沟通姿态卡
2. 抽取一张场景卡
3. 先用第一种姿态回应，再转化为第二种姿态
4. 最后尝试用一致性沟通回应
5. 其他玩家给予反馈

### 4.3 "家庭雕塑"模式
结合萨提亚的家庭雕塑技术，通过身体姿势表达家庭关系。
1. 抽取家庭互动卡
2. 玩家根据卡片提示，用身体姿势表达家庭关系
3. 其他玩家猜测并讨论这种关系模式
4. 尝试调整姿势，创造更健康的关系模式

### 4.4 "情绪探索"模式
专注于情绪的识别、表达和调节。
1. 每位玩家抽取3张情绪表达卡
2. 分享一个与这些情绪相关的个人经历
3. 使用资源卡，讨论如何调节这些情绪
4. 练习表达"我感到...因为..."的一致性表达

## 5. 引导与反思环节

### 5.1 游戏中的引导原则
- 保持好奇和尊重
- 避免评判和建议
- 关注感受和需求
- 鼓励深度探索
- 确保每个人都有表达的机会

### 5.2 反思问题示例
- "你注意到自己常用的沟通姿态是什么？"
- "当你使用不同沟通姿态时，你的感受有何不同？"
- "你发现自己的冰山深层有什么模式吗？"
- "这个游戏过程中，你有什么新的认识或洞见？"
- "你想在日常生活中尝试哪些新的沟通方式？"

### 5.3 结束仪式
1. 每位玩家选择一张资源卡
2. 分享一个游戏中的收获和一个未来的行动意向
3. 用一致性沟通表达对其他家庭成员的一个欣赏

## 6. 游戏注意事项

### 6.1 安全原则
- 尊重每个人的边界和选择
- 可以选择"暂停"或"跳过"某些问题
- 保持游戏氛围轻松、支持性
- 避免使用游戏内容相互指责或批评

### 6.2 引导者建议
- 熟悉萨提亚模式的基本概念
- 关注游戏过程中的情绪变化
- 适时提供支持和引导
- 根据参与者的需要调整游戏节奏和深度

### 6.3 适用场景
- 家庭日常沟通
- 家庭冲突解决
- 亲子关系增进
- 伴侣关系修复
- 家庭治疗辅助工具
