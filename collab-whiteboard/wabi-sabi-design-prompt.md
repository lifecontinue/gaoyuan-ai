# Wabi-Sabi 设计提示词（Design Prompt）

> 适用对象：素白板 / 同类工具型 Web 应用
> 基调：不完美即美、自然质朴、留白与安静。拒绝高饱和渐变、霓虹光晕与"AI 通用紫蓝"。

---

## 1. 设计哲学（为何如此）

Wabi-Sabi 源自日本侘寂美学，强调**粗糙、朴素、不对称、随时间留下的痕迹**。映射到界面：
- 用「纸感」代替纯白塑料感；
- 用「墨色」代替纯黑；
- 用「陶土 / 苔绿 / 褪色靛」作克制强调色，而非大面积铺色；
- 大量留白 + 轻微不对称构图，让内容呼吸；
- 动效缓慢、克制，像呼吸而非弹跳。

---

## 2. 配色（Palette）

| 角色 | Token | 值 | 用途 |
|---|---|---|---|
| 纸面 | `--paper` | `#F4F1E9` | 画布 / 主背景（暖白，非 `#FFF`） |
| 次级纸 | `--paper-2` | `#ECE5D6` | 卡片 / 便签底 |
| 墨色 | `--sumi` | `#2B2925` | 顶栏 / 正文 / 描边（暖近黑，非 `#000`） |
| 褪色字 | `--muted` | `#8A8275` | 次要文字、占位 |
| 陶土（强调） | `--clay` | `#A9694A` | 选中态 / 激活工具 / 关键操作 |
| 苔绿 | `--moss` | `#7C8B6F` | 辅助图形填充 |
| 褪色靛 | `--indigo` | `#5B6B7A` | 辅助强调 |
| 石色 | `--stone` | `#A8A294` | 分隔 / 禁用 |
| 网格细线 | `--line` | `#DBD3C4` | 画布网格 |
| 网格粗线 | `--line-2` | `#D2C8B5` | 每 5 格主网格 |
| 边框 | `--border` | `#CDC3B0` | 面板 / 输入框描边 |

**规则**：全站仅 1 个强调色（陶土），饱和度 < 80%；禁止纯黑 `#000`、纯白 `#fff`、霓虹色。

---

## 3. 材质（Material / Texture）

- 画布使用**宣纸暖白** + 极淡暖灰网格，营造手工纸感；
- 顶栏为**墨色哑光**（无高光渐变），底部一道 `rgba(244,241,233,.08)` 细线收口；
- 便签为**哑光纸卡**，1px 暖色描边 + 柔和扩散投影，避免塑料反光；
- 一律**无玻璃拟态（glassmorphism）滥用**、无外发光。

---

## 4. 留白（Whitespace）

- 顶栏高度固定 `56px`，工具组之间 `12–14px` 间距；
- 面板 / 卡片内边距 `10–14px`，元素间距 `6–8px`；
- 画布默认**大量留白**，对象初始散布在外扩边距处，不堆挤；
- 构图**轻微不对称**：品牌居左、工具居中、操作居右，符合阅读动线。

---

## 5. 字体（Typography）

| 用途 | 字体栈 | 说明 |
|---|---|---|
| 标题 / 品牌 | `"Songti SC","STSong",Georgia,serif` | 衬线，传递沉静人文感 |
| 正文 / UI | 系统无衬线（`-apple-system, "PingFang SC", "Microsoft YaHei"`） | 清晰易读 |
| 字号 | 流式 `clamp()`，正文 `14px`，辅助 `12–13px` | 避免超大标题 |

**规则**：工具型界面正文禁用衬线；品牌 / 大标题可用衬线制造记忆点；行高 `1.4`。

---

## 6. 圆角（Radius）

- 便签 / 卡片：`10px`（柔和而非圆润气泡）；
- 面板 / 菜单：`12–14px`；
- 按钮：`9px`；
- 手柄 / 小点：`3–6px`；
- 允许**轻微不规则**（如便签 10px、图形 8px），比全站统一圆角更有手工感，但不可极端。

---

## 7. 阴影（Shadow）

- 标准：`0 8px 22px rgba(43,41,37,.14)`（暖色、低透明、大扩散）；
- 轻量：`0 3px 10px rgba(43,41,37,.12)`；
- 选中态：`0 0 0 2px var(--clay), 0 12px 26px rgba(169,105,74,.22)`；
- **禁止**硬黑阴影、纯黑描边、霓虹外发光。

---

## 8. 动效（Motion）

- 缓动：`cubic-bezier(.22,1,.36,1)`（ease-out，缓慢收尾）；
- 时长：`150–220ms`，界面状态切换用；
- 特性：工具激活有 `transform:scale(.93)` 触感反馈；面板淡入 `opacity + translateY(-4px)`；
- 禁用：回弹 / 弹性缓动、布局属性动画（只动 `transform`/`opacity`）；
- **无障碍**：`@media (prefers-reduced-motion: reduce)` 下全部停用过渡与动画。

---

## 9. 应用对照（本文件已落地项）

- 顶栏墨色哑光 + 陶土激活态 ✅
- 画布宣纸暖白 + 暖灰网格 ✅
- 便签哑光纸卡 + 柔和投影 ✅
- 选中态陶土描边 ✅
- 字体：品牌衬线、UI 无衬线 ✅
- 圆角 9–14px 分级 ✅
- 动效 ease-out + reduced-motion 兜底 ✅
- 单一强调色（陶土），无霓虹 ✅
