| 你想改什么 | 改哪里 | 备注 |
|---|---|---|
| 主色 / 文字色 / 背景色 | `css/style.css` 的 `:root` 变量 | 所有组件都引用变量，改一处全局生效 |

## 1. 整体架构

页面是**单页、离线、无构建**的纯静态应用。整页只有**一个主界面 = 全屏星空**，其余所有功能都以「浮层 / 抽屉 / 菜单 / 模态」叠加其上。

- `<body class="galaxy-mode">`：深空渐变背景，禁用滚动条（`overflow:hidden`）。
- `#galaxy`（`position:fixed; inset:0; z-index:1`）：星空画布容器，内部 `<canvas id="galCanvas">` 由 `js/galaxy.js` 绘制 3D 星座。
- 浮层组件（见下表）全部 `fixed` 定位、`z-index ≥ 10`，互不嵌套、各自独立显隐。

## 2. 设计令牌（`:root` 变量）

所有颜色、字体、圆角、阴影都集中在 `:root`。**调整视觉统一从这里改。**

```css
:root{
  --bg0:#070912; --bg1:#0d1024; --bg2:#161a36;          /* 背景三阶（主背景用 --bg0）*/
  --glass:rgba(22,26,48,.55);                            /* 浮层玻璃底色 */
  --glass-strong:rgba(24,28,54,.86);                     /* 弹窗/信息卡更实的玻璃 */
  --stroke:rgba(255,255,255,.12);                        /* 主描边 */
  --stroke-soft:rgba(255,255,255,.07);                   /* 次级描边（分隔线用）*/
  --txt:#eef1fb; --txt-dim:#aab0c8; --txt-faint:#717796;/* 文字三档：主/次/弱 */
  --accent:#ff7c3a; --accent2:#6ea8ff; --accent3:#b98bff;/* 强调三色：橙 / 蓝 / 紫 */
  --ok:#5fd39a; --mid:#ffd27a; --no:#ff8a7a; --pending:#9aa2bd; /* 状态四色：达标/中等/不达标/待观察 */
  --r:18px; --r-sm:12px;                                /* 大圆角 / 小圆角 */
  --shadow:0 18px 50px rgba(0,0,0,.45);                  /* 浮层投影 */
  --serif:"Noto Serif SC","Songti SC","PingFang SC","Microsoft YaHei",serif; /* 标题衬线 */
  --sans:"PingFang SC","Microsoft YaHei","Hiragino Sans GB",system-ui,sans-serif; /* 正文无衬线 */
  --mono:"Cutive Mono","JetBrains Mono",Consolas,monospace; /* 英文/编号等宽 */
}
```

**使用约定**

- 背景渐变（body.galaxy-mode）：三层 `radial-gradient` 叠加——右上蓝紫光晕、左下橙光晕、中心深空 `#0a0d1e→#06080f`。
- 强调色 `--accent`（橙）用于品牌、主按钮、选中态、阶段切换高亮；`--accent2`（蓝）用于 AI / 链接；`--accent3`（紫）用于 AI 头像。
- 状态色 `--ok/--mid/--no/--pending` 同时驱动 SVG 图表配色与评级标签 `.lv-*`。

## 3. 玻璃拟态基础类 `.glass`

所有主浮层（topbar / side-panel / ai-panel / menu / modal）都挂 `.glass`：

```css
.glass{
  background:var(--glass);
  backdrop-filter:blur(22px) saturate(140%);
  -webkit-backdrop-filter:blur(22px) saturate(140%);
  border:1px solid var(--stroke);
  box-shadow:var(--shadow);
}
```

> 调整磨砂强度：改 `blur(22px)`；改通透度：改 `--glass` 的 alpha（`.55`）；改投影：改 `--shadow`。

### 4.4 右侧万能抽屉 `.side-panel`（id `#sidePanel`）

- `fixed; top:84 right:14 bottom:14; width:430（max 100vw-28）; z-index:14`。
- 默认 `transform:translateX(calc(100% + 24px))`（屏幕外）；`.open` → `transform:none`；过渡 `.32s cubic-bezier(.4,0,.2,1)`。
- 内部：`.sp-head`（面包屑 + 关闭按钮）/ `.sp-crumbs`（12px 弱，当前层级 `b` 14px）/ `.sp-body`（flex:1 可滚动，padding 16）。
- **共存规则**：`body.sp-open .ai-panel{right:auto;left:14px;}` —— 抽屉打开时 AI 面板自动挪到左侧，避免遮挡（见 §4.5）。
- 内容：所有下钻详情、菜单面板、表单列表均由 `app.js` 的 `Side.render(crumbs, html, refresh)` 注入 `#spBody`，并用 `openNode / openMenu / openDomain / openSubject` 等触发。

### 4.5 AI 浮动面板 `.ai-panel`（id `#aiPanel`）

- `fixed; top:84 right:14 bottom:14; width:368; z-index:13`，同抽屉过渡。
- `.collapsed` → `translateX(calc(100% + 24px))`（收起态，由 `#aiMin` 切换）。
- 内部结构（均见 `index.html`）：
  - `.ai-header`：`.ai-avatar`（紫蓝渐变 34×34）+ 标题 + 状态点 + 收起按钮。
  - `.ai-context`：蓝底提示条，显示当前上下文（`#aiContextText`，由 `AI.setContext` 更新）。
  - `.ai-messages`：消息流，`flex:1` 可滚动；气泡用 `.msg / .msg-ai / .msg-user / .msg-bubble / .msg-time`。
  - `.ai-quick`：快捷动作胶囊（`.quick-chip`，`app.js` `renderQuick` 注入）。
  - `.ai-composer`：`#aiInput`（textarea，min 42 / max 120）+ 发送按钮 `.composer-btn.send`（橙渐变）。
- 气泡样式：AI 气泡 `rgba(255,255,255,.06)` 左上尖角；用户气泡橙渐变右下尖角。

### 4.6 全局菜单 `.menu` + `.menu-mask`

- `.menu-mask`：`fixed; inset:0; z-index:20`；半透黑 + `blur(3px)`；`.show` 显隐。
- `.menu`：`fixed; top:14 right:14 bottom:14; width:340; z-index:21`；`.glass`；默认 `translateX(100%+24)` 隐藏，`.open` 显示，过渡 `.3s`。
- 内部：`.menu-head`（品牌 + 标题 + 关闭）/ `.menu-section`（分组小标题）/ `.menu-item`（图标 `.mi-ic` 38×38 + 文案 `.mi-tx`：b 14 / i 11.5 弱）。
- 五个入口：`summary`(📄 综合评价) / `parent`(❤️ 家长记录) / `subjects`(📚 学科维度) / `data`(💾 数据管理) / `about`(ℹ️ 关于)。点击 → `app.openMenu(type)`。

### 4.7 模态框 `.modal-mask` + `.modal`（id `#modalMask` / `#modal`）

- `.modal-mask`：`fixed; inset:0; z-index:30`；黑 60% + `blur(4px)`；flex 居中；`.show` 显隐。
- `.modal`：宽 `min(640,100%)`；最大高 88vh 可滚动；圆角 `--r`；内边距 22；默认 `translateY(10) scale(.98)`，`.show` 复位。
- 内部由 `app.modal(title, body, footer)` 注入：`<h2>` 标题 + `.modal-body` + `.m-foot`（右对齐按钮组）。表单字段用 `.field`（见 §5）。

### 4.8 Toast `.toast`（id `#toast`）

- `fixed; 左中下(50%, bottom:30); z-index:40`；`glass-strong` + `blur(18px)`；`.show` 显隐（上滑淡入）。
- 由 `app.toast(msg)` 调用，2.2s 自动消失。

## 7. 响应式与打印

### 移动端 `@media (max-width:880px)`
- `.topbar`：换行、高度自适应；搜索框 `order:3` 整行（`flex-basis:100%`）。
- `.side-panel / .ai-panel`：宽 `100vw-28`，高度 `72vh`，底部贴边（`top:auto`）。
- `.ai-panel`：仍 `top:84 bottom:14`（与抽屉上下错开）；`body.sp-open .ai-panel` 仍左移。
- `.gal-hud` / `.gal-infocard`：下移避让顶栏（`top:140`）；信息卡宽 240。
- `.gal-legend`：隐藏。

### 打印 `@media print`
- `body` 白底可滚；隐藏 `#galaxy/.topbar/.side-panel/.ai-panel/.menu/.modal-mask/.toast/.gal-legend`。
- 仅 `.modal-mask.show` 显示并转白底无遮罩；`.modal` 去边框去阴影黑字；`*{color:#111}` 强制黑字。
- 用途：综合评价报告「打印 / 导出 PDF」。
