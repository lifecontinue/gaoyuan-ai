# 工具前端设计说明（团团成长星空）

> 版本：v1.0 · 2026-08-04
> 适用代码：`团团成长评价系统/`（星空核心架构版）
> 配套文档：`前端设计说明.md`（视觉令牌 / 组件样式）、`docs/可扩展架构方案.md`、`docs/系统设计Prompt.md`
> 本文聚焦：**功能模块 · 界面结构 · 交互流程 · 技术选型建议 · 视觉优化设计**，面向工程落地。

---

## 0. 一页总览

| 项 | 结论 |
|---|---|
| 产品形态 | 单页离线 Web 应用（本地双击即用，无构建、无外部 CDN）；**AI 云端能力需 Node 代理（`server/`，Key 存服务端、前端免输入），纯静态打开时自动降级本地规则** |
| 主界面 | **唯一主界面 = 全屏 3D 星空**；中心=团团，幼儿园 6 领域臂 / 小学 9 学科臂，叶子=指标 |
| 功能承载 | 所有功能以「浮层」叠加：右抽屉（详情）、AI 面板、全局菜单、模态、Toast |
| 数据 | 种子数据只读（`data.js` / `subjects_p3.js`）+ 家长数据 LocalStorage（`store.js`）叠加 |
| 渲染 | 纯 Canvas（星空）+ 自绘 SVG（图表）+ 字符串模板注入 DOM（抽屉/面板） |
| 规模 | `app.js` 720 行 / `galaxy.js` 565 行 / `style.css` 376 行 / `index.html` 154 行 |

## 1. 功能模块

按「可独立维护、可独立替换」的边界拆分。每个模块给：职责 / 代码归属 / 对外的主要入口。

### M1 星空可视化引擎（核心）
- **职责**：3D 星座建模与渲染（节点、连线、旋转、缩放、悬停信息卡、图例、HUD、视角控制）。
- **代码**：`js/galaxy.js`（`window.Galaxy`）。
- **公开方法**：`enter(stage)` / `exit()` / `toggle()` / `buildNodes(stage)` / `_buildKindergarten` / `_buildPrimary` / `render()` / `clickNode(n)` / `focusNode(q)` / `updateInfo(n)` / `updateHud()` / `showInfo(n)`。
- **边界**：只负责「画与镜头」，**不写业务文案**；节点点击通过 `window.TT.openNode(node)` 回调给应用层。
- **节点模型**：`{ id, kind: center|domain|subdomain|indicator|subject|theme|pindicator, label, en, color, size, pos3, data }`。

### M2 下钻详情抽屉（SidePanel）
- **职责**：承接一切「点开看详情」的内容（概览/领域/子维度/指标/学科/菜单面板），面包屑 + 可滚动正文。
- **代码**：`js/app.js` 的 `Side` 对象 + `renderCenter/renderDomain/renderSubdomain/renderIndicator/renderSubject/renderTheme`。
- **契约**：`Side.render(crumbs, html, {fn,args})`；`Side.refresh()` 用 `cur` 重渲染当前视图（数据变更后刷新）。

### M3 AI 成长顾问
- **职责**：按阶段切换的「双 Agent」成长分析——幼儿园 `deepseek-k`（幼儿发展评估专家）/ 小学 `deepseek-p`（学科评估专家）+ 本地规则兜底；支持欢迎语、趋势/薄弱/计划/报告/活动/学科 6 类快捷动作、上下文感知问答。
- **代码**：`js/ai/orchestrator.js`（`welcome/action/reply` + `runWithFallback` 云端失败回落本地）+ `js/ai/provider-registry.js`（`register/list/pick(stage)`）+ `js/ai/providers/*`（`deepseek-core.js` 共享内核、`deepseek-k-provider.js`、`deepseek-p-provider.js`、`rule-provider.js`、`child-info.js`）。`js/ui/ai-panel.js` 负责面板渲染与交互（`init/refreshWelcome/onStageChange/toggle/renderStatus`）。
- **现状**：**双 Agent（云端 LLM）已接入**，Key 存于服务端 `server/.env`，前端经同源代理 `/api/ai/chat` 调用，用户免输入；代理不可达/无 Key 时自动回落本地规则分析，基础功能不中断。
- **上下文**：`ContextBuilder.build()` 组装 `{route,domain,metric,menu,stage}` + 领域统计快照；阶段切换触发 `AIPanel.onStageChange()` 以当前 Agent 刷新欢迎语。

### M4 全局导航与菜单
- **职责**：顶栏（品牌/搜索/阶段迷你/AI/菜单）+ 全局菜单（综合评价/家长记录/学科维度/数据管理/关于）。
- **代码**：`index.html` 结构 + `app.js` `openMenu(type)`、`openSearchResult`、菜单事件。
- **菜单 type**：`summary | parent | subjects | data | about`。

### M5 搜索
- **职责**：跨「领域/子维度/指标/学科/主题」全文索引与即时下拉；命中后定位到星空节点 + 打开详情。
- **代码**：`app.js` `buildSearchIndex / doSearch / openSearchResult`；`galaxy.focusNode(q)` 负责镜头聚焦。

### M6 家长记录
- **职责**：观察笔记 CRUD、习惯打卡网格、家长测评（复用指标模板自测）。
- **代码**：`app.js` `renderParent(tab) / renderNotes / renderHabits / renderParentAssess / renderAssessEditor`；存储走 `store.js`。

### M7 综合评价
- **职责**：按需汇总测评 + 家长记录生成报告，支持打印 / Markdown 导出。
- **代码**：`app.js` `renderSummaryList / summaryData / summaryDocHtml / openSummaryForm / summaryMarkdown / summaryPeriodHtml`。

### M8 数据管理
- **职责**：备份（导出 JSON）/ 恢复（导入 JSON）/ 清空重置；数据源清单与档案索引。
- **代码**：`app.js` `renderData / exportData / importData / resetData`；`store.js` `exportJSON / importJSON / reset`。

### M9 学科维度（小学三年级）
- **职责**：9 学科主题卡、可评指标、学习路径（教育知识图谱 / 课标进阶来源徽标）。
- **代码**：`app.js` `renderSubjects / renderSubject / themeBodyInner / subjectLearningPathsHtml`；数据 `subjects_p3.js`。

### M10 阶段切换
- **职责**：幼儿园(k) ⇄ 小学(p) 全局切换，重建星空节点、刷新索引与上下文；持久化 `settings.lastStage`。
- **代码**：`app.js` `setStage(st)` + `stagePeriods / allPeriods / rowsOf / latestFull`。

### M11 基础设施 UI
- **职责**：模态表单（`modal/closeModal`）、轻提示（`toast`）、通用容器类。
- **代码**：`app.js` 顶部 + `style.css` 通用组件库。

### M12 图表
- **职责**：雷达 / 折线 / 堆叠柱 自绘 SVG，零依赖。
- **代码**：`js/charts.js`（`window.Charts`）。

## 2. 界面结构（信息架构）

### 2.1 布局骨架
```
body.galaxy-mode（深空背景，overflow:hidden）
├── #galaxy (fixed, z1)              ← 唯一主界面（Canvas 3D 星空）
│   ├── .gal-mark / .gal-hud / .gal-legend / .gal-stage / .gal-toolbar / .gal-infocard
├── header.topbar (fixed, z12)       ← 品牌 / 搜索 / 阶段迷你 / AI / 菜单
├── aside.side-panel (fixed, z14)    ← 右抽屉：所有下钻详情 + 菜单面板
├── aside.ai-panel (fixed, z13)      ← AI 面板：上下文条 / 消息流 / 快捷动作 / 输入
├── nav.menu + .menu-mask (z21/z20)  ← 全局菜单
└── .modal-mask>.modal (z30) / .toast (z40)
```
> 布局原则：**星空恒驻、内容浮层化、抽屉优先、模态兜底**。任一时刻最多一个抽屉 + 一个 AI 面板 + 一个模态。

### 2.2 下钻层级（同一抽屉内）
```
中心(center) 整体概览
 └─ 领域(domain)  领域详情
     └─ 子维度(subdomain)  指标列表
         └─ 指标(indicator)  评价/补充评价/历史点
小学侧：
学科(subject)  学科详情（主题卡+学习路径）
 └─ 主题(theme)  展开主题卡
     └─ 指标(pindicator)  定位到所属主题
```
> 层级由 `openNode(node.kind)` 路由；`#spCrumbs` 反映当前路径；`Side.cur` 支撑「刷新回原视图」。

### 2.3 状态共存规则
- 抽屉打开 → `body.sp-open` → AI 面板自动左移（`body.sp-open .ai-panel{right:auto;left:14px}`）。
- 菜单/模态打开 → 遮罩层 `.show`，点击遮罩/关闭按钮关闭。
- AI 面板可 `.collapsed` 收起；移动端宽度切换触发时自动展开。

## 3. 交互流程

> 记法：`[用户动作] → [系统函数] → [结果]`。函数均见 `js/app.js` / `js/galaxy.js`。

### F1 首次进入 / 浏览
进入页面 → `init()` → `buildSearchIndex()` + `bindEvents()` + `Galaxy.enter(stage)` + `AI.init()` → 星空自转、AI 欢迎语、HUD 显示阶段计数。

### F2 下钻查看（最核心）
`点击星空节点 → Galaxy.clickNode(n) → TT.openNode(n)` →
按 `n.kind` 分流：
- `center` → `renderCenter`（雷达+KPI+6领域）
- `domain` → `renderDomain`（趋势+子维度+长期待突破）
- `subdomain` → `renderSubdomain`（指标+补充评价）
- `indicator` → `renderIndicator`（评级+历史点+添加观察）
- `subject` → `renderSubject`（主题卡+学习路径）
- `theme/pindicator` → `renderTheme`（展开所属主题）
→ `Side.render(crumbs, html, cur)` → `AI.setContext(...)`。

### F3 指标评价（家长补充）
详情内点评级按钮 → `TT.rate / TT.rateNote / rateIndicator` → `S.rate(...)` 写库 → `Side.refresh()` 重渲染当前视图 → 数据即时生效。

### F4 AI 提问 / 快捷动作
点快捷胶囊 → `AI.action(id)`；或输入回车 → `AI.reply(text)` → `AI.post(role, html)` → 消息流刷新并滚动。`AI.contextText()` 随 `setContext` 更新顶部上下文。

### F5 家长记录
菜单 `parent` → `renderParent(tab)` → 切 tab（notes/habits/assess）→ 观察 `addNote` / 打卡 `toggleHabit` / 测评 `addParentPeriod+rate` → 均写 `store` 并 `refreshSide()`。

### F6 生成综合评价
菜单 `summary` → `openSummaryForm()`（模态选期次）→ `S.addSummary(...)` → `renderSummaryList()` → 打开报告 `summaryDocHtml`（模态）→ `printSummary()`（打印）/ `exportSummaryMD()`（导出 .md）。

### F7 阶段切换
点 `.gal-stage` / `.stage-mini` 按钮 → `TT.setStage(st)` → 更新按钮态 + `Galaxy.enter(st)`（重建节点）+ `buildSearchIndex()` + `AI.setContext` → `settings.lastStage` 持久化。

### F8 数据管理
菜单 `data` → `renderData()` → 导出 `exportData()`（JSON 下载）/ 导入 `importData()`（FileReader+`S.importJSON`）/ 重置 `resetData()`（`S.reset`）。

### F9 搜索定位
`#searchInput` 输入 → `doSearch(q)` → 下拉 `.sr-item` → 点击 → `openSearchResult(item)` → `Galaxy.focusNode(...)`（镜头聚焦）+ 对应 `open*` 打开详情。

## 4. 技术选型建议

### 4.1 现状评估
| 维度 | 现状 | 评价 |
|---|---|---|
| 运行形态 | 离线单文件 SPA，无构建 | ✅ 符合「家长本地隐私」定位，部署零成本 |
| 语言/框架 | 原生 HTML/CSS/JS（ES6 IIFE） | ✅ 零依赖；⚠️ 单文件 720 行，模块化弱 |
| 渲染 | Canvas(星空) + SVG(图表) + 字符串模板(DOM) | ✅ 轻量；⚠️ 模板拼接易出错、难测试 |
| 状态 | 局部变量 + `window.TT/Galaxy` | ⚠️ 全局单例，缺少明确事件流 |
| 数据 | LocalStorage | ✅ 够用；⚠️ 无 schema 校验、无迁移版本 |
| AI | 双 Agent（云端 LLM）+ 本地规则兜底 | ✅ Provider 抽象已完成，按阶段自动择优、云端失败回落本地 |
| 测试 | jsdom+vm 无头回归 | ✅ 已有；建议常态化 |

### 4.2 选型矩阵（按优先级）
| 方向 | 选项 A（推荐·渐进） | 选项 B（中期） | 触发条件 |
|---|---|---|---|
| 模块化 | ES Modules 拆分（`js/modules/*`）+ `<script type="module">` | 引入构建（Vite）| 仍想双击即用 → A；要打包/TS/依赖管理 → B |
| 组件化 | 保留模板函数 + 抽取纯 render 函数 | Web Components / 轻框架（Preact）| 交互复杂度继续上升 → B |
| 类型安全 | JSDoc `@typedef` | TypeScript | 多人协作/长期维护 → B |
| AI 能力 | 双 Agent（deepseek-k/p）+ 本地规则兜底，Key 存服务端、前端免输入 | 多模型/多厂商路由、可配置开关 | 见架构文档 §5.5 |
| 离线增强 | 维持现状 | PWA（manifest+SW 缓存）| 要「装到手机主屏」→ B |
| 数据层 | LocalStorage + schema 版本号 | IndexedDB（Dexie）| 记录量大/二进制附件 → B |
| 测试 | 维持 jsdom+vm 回归 | + Playwright 视觉回归 | 需要视觉断言 → B |

### 4.3 推荐路径（不推倒、可落地）
1. **现在**：ES Modules 已拆分（`js/core|domain|data|ui|viz|ai`），AI 已抽象为 Provider 接口（本地规则 = 默认实现，云端双 Agent = 增强实现）。
2. **3 个月内**：给 `store.js` 加 **schema 版本 + 迁移钩子**；按需接入更多云端 LLM Provider（多厂商路由，可配置开关）。
3. **需要时**：再引入 Vite + TS + PWA；**不要在能力建设完成前上重型框架**。

> 核心判断：本项目价值在「数据 + 交互 + AI 分析」，不在框架。优先把 **模块边界与 AI 接口** 立起来，框架后置。

## 5. 视觉优化设计（基于现有深空玻璃拟态）

> 原则：**延续现有风格做精修，不推倒重做**。以下每条均可独立实施、且只动 `style.css` / 少量模板。

### 5.1 设计系统层
- **建立间距刻度**：现有间距散落（5/6/8/10/12/14/16/22），建议收敛为 `--s1:4 --s2:8 --s3:12 --s4:16 --s5:24` 变量并全局替换，提升节奏一致性。
- **字重/字号阶梯**：定义 `--fs-disp(30) --fs-h1(21) --fs-h2(15) --fs-body(13.5) --fs-sub(11.5) --fs-cap(10.5)`，替换散点硬编码。
- **动效令牌**：抽出 `--ease:cubic-bezier(.4,0,.2,1) --t-fast:.15s --t-mid:.3s`，统一过渡时长。

### 5.2 星空层
- **悬停信息卡**：当前右上角浮卡信息密度高；建议分组标题（`.sec-t`）+ 数值右对齐，扫描更快。
- **图例**：补充「节点大小=指标数 / 颜色=得分冷暖」说明，降低首次认知成本。
- **HUD**：将「期次数/领域数」改为可点击，点击直接打开对应总览，减少操作路径。

### 5.3 抽屉（最高频，重点）
- **信息层级**：在 `renderCenter/renderDomain` 顶部加「结论一句话」（AI.domainSummary 已有，可前置展示），再展开图表。
- **列表项**：`.list-item` 右侧分数建议统一 `.li-score` 衬线大号 + 趋势小箭头，视觉锚点更强。
- **评级反馈**：`.rate-btn.sel` 选中态加轻微 `scale(1.03)` + 微投影，强化「已选」感知。
- **空状态**：统一 `.empty` 文案模板（图标+一句话+主按钮），减少「看起来像坏了」的感觉。

### 5.4 AI 面板
- **消息气泡**：AI 气泡内嵌图表/标签时增加内边距与分隔线；为「可点建议」提供 `.quick-chip` 同款胶囊样式。
- **上下文条**：当前上下文可点击（点击领域名直接下钻），形成「AI ↔ 详情」双向跳转。

### 5.5 顶栏 / 菜单
- **搜索**：下拉项加分组标题（领域/学科/指标），命中关键词高亮（`.sr-tx mark`）。
- **菜单项**：hover 增加左侧 2px 强调竖条，强化可点性。

### 5.6 一致性与无障碍
- **焦点可见**：所有 `button/input` 补 `:focus-visible` 描边（用 `--accent2`），键盘可用。
- **对比度**：`--txt-faint #717796` 在深底上偏弱，关键信息（如 `.gi-hint`/`.tb-sub`）建议提到 `--txt-dim`。
- **动效降级**：`@media (prefers-reduced-motion: reduce)` 下关闭星空自转与位移过渡。

> 落地建议：先实施 5.1（令牌化）与 5.3（抽屉层级），收益最大、改动最小。
