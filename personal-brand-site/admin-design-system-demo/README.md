# 21TB 管理端设计规范原型

静态可点击 demo，用来验证 DESIGN.md **1.1-arco-base+sketch-ref**：实现 token 仍是 Arco/`--ads-*`，版式跟 Sketch 系统设置案例（侧栏、已选条数、抽屉表单）。

## 打开方式

无需构建。任选其一：

1. 用浏览器直接打开 `index.html`（文件协议即可）。
2. 本地静态服务：

```bash
python3 -m http.server 4821
```

然后访问 `http://127.0.0.1:4821/`。

## 页面里点什么

- **平台设置 → 岗位管理**：筛选、多选表格、底栏「已选 N 条」+ 分页。
- **新增 / 编辑**：右侧 **640** 抽屉（标签、输入、开关、主/默认按钮）。
- **查看**：右侧 **960** 分组抽屉。
- **删除**：先确认再从列表去掉。
- 侧栏底 **组件规范**：主按钮 / 默认 / 危险 / 文字按钮和 Tag，颜色全部走 `--ads-*`。

对照清单见 `COMPARE.md`。Token 写在 `css/ads.css` 的 `:root`。
