Changes for this game: excerpt selection, a 200ms wraparound crossfade,
constant-gain loudness adjustment targeting -23 LUFS, and 96kbps MP3 encoding.
No endorsement by the composer is implied.

The attribution appears inside the game's “声音与显示 → 音乐来源与许可” panel.
The adjacent credits.json records source URLs, excerpt positions and file hashes.
Original music and license were checked against the composer's official track
catalog and track page attribution on 2026-10-28.

Reproduce edits with `python qa/prepare-music.py` from the editable game project
(requires FFmpeg and NumPy). Original downloads stay in the ignored local cache.
