【课程学习】课堂伙伴 · 多智能体旁路问答

给开发的开工文档：只写要做什么和必须满足的规则。AI 部分把导演编排、工具契约、确定性兜底和 Eval 写死，避免实现漂。

受众
前端 / 后端 / Agent
架构
Supervisor + Tool-calling
角色
讲师 ×1 + 同学 ×N
默认上限
max_agent_turns = 3（硬顶 6）

本轮交付结果

  1. 系统设置 · 课堂伙伴：启停、选用讲师/同学、编辑头像/名称/人设/音色、人设润色、添加伙伴生成。
  2. 学习页侧栏 · 课堂伙伴：学员提问后，静默导演调度多角色可见回答 + TTS，支持停止 / 重生成 / 笔记。
  3. 服务端编排：工具面固定三工具；硬规则确定性兜底；回合回退契约可测。

实验室参考实现：D:\software\langgraph\classroom_roles\。生产可换运行时，但工具名、硬规则、Eval 用例与对外行为必须对齐。

2. 名词与范围

名词含义产品面
课堂伙伴设置入口名 + 学习页侧栏品牌名设置 / 学习页
讲师唯一主讲角色，首条实质台词必须来自他type=teacher
同学追问/补充角色，可 0～Ntype=student
导演静默调度器，不输出可见台词Supervisor LLM + 规则引擎
一轮 / turn学员一次提问到终态（cue/close）带 turn_id
旁路问答听课同时提问；结束问答不结束整课学习页侧栏

配置 ↔ 运行时

  • 设置页保存的就是对话角色本身：讲师必选 1、同学可多选。无「组班」步骤。
  • 关闭「课堂伙伴」后：学习页用系统默认（AI 讲师 + 1 位同学），设置页不展示角色库。
  • 服务端收到非法类型（如历史助教）丢弃；多余讲师只留第一位；无讲师则注入默认讲师。

3. 功能需求（要做什么）

D01 启停与默认

  • 管理员可启用/关闭课堂伙伴。
  • 关闭：隐藏角色库；学习页问答用默认角色（AI 讲师 + 1 同学）。
  • 开启：保存勾选角色及其人设/音色；学习页直接读取。

D02 角色资料

  • 类型仅讲师 / 同学。讲师必选且不可取消；同学可多选（可为 0）。
  • 每位可维护：头像、名称、人设、音色。
  • 讲师人设同样可编辑（与同学一致入口）。

D03 人设润色

  • 人设框内润色入口（通用图标）；无内容不可点；润色中动画；可再次润色。
  • 失败：回落系统默认人设 + 可重试提示（文案不含外部竞品名）。
  • 输出结构必须含五节：Personality / Environment / Goal / Guardrails / Tone。

D03b 添加伙伴（同学生成）

  • 设置页「添加伙伴」走生成流程：一次产出 name / voice / avatar 档 / prompt。
  • type 固定 student；音色必须落在白名单；名称避开已有角色。
  • 接口：POST /role/companion（可回落 /prompt/generate + 本地规则）。

D04–D06 导演调度（详见 §4）

  • 导演仅工具决策，无可见气泡。
  • 工具：call_agent / cue_user / close_session。
  • 硬规则 + 确定性兜底；终态互斥。

D07 学习页对话 UI

  • 顶栏：品牌「课堂伙伴」+ 角色头像条（讲师首位）+ 新建 / 关闭。
  • 空会话：参与角色说明 + 推荐问题（点击即发）。
  • 等待：讲师「正在思考」占位；发送键变「停止」。
  • 气泡：头像 + 名 + 讲师/同学标签；同学气泡浅灰区分。
  • close 后分隔：「本次问答已结束 · 可继续听课，或直接提新问题」（不暴露 end_reason 代码）。
  • 停止分隔：「已停止本次回答」。
  • 笔记：空态 / 撰写 / 列表 / 详情（与原型四态一致）。
  • 无障碍：读屏播报区；可见焦点；「减少动态效果」时关闭说话/思考动画。

D07b 打断与回退

操作回答中回答后服务端上下文
历史「播放」置灰，不打断可切播 / 停当前不变
重新生成隐藏仅最后一轮最后卡片；整轮替换整轮撤回后重答
停止 · 思考中取消请求 + 分隔—问题 +「学员中途停止」，无角色台词
停止 · 出字/播报保留已显文字，停语音，后续角色不出场—只保留已展示文字 + 停止注记
关面板 / 新建等同停止；旧回合迟到数据丢弃新建清空同停止 / 新会话
错误「重试」—整轮重答，不重复插用户问题先撤回失败轮

原则：同一时刻一个回答、一个声音；只有明确中断操作才停；没展示的台词不进上下文；过期 turn_id 数据丢弃。

D08 文音

  • 出字同时预取 TTS；字流与音频都就绪后播放。
  • 不展示「正在合成」状态条。
  • 失败：台词仍完整；语音图标变黄可点重试；可回落浏览器语音。

D09 观测

  • 生产默认不回传 director_trace；调试可开。
  • 须能支撑 §5 Eval 抽检。

情况表现文案

4. Agent 编排规格

架构：Supervisor（导演）+ Tool-calling Subagents（角色）。不做 Swarm、不做角色互 handoff、不做并行多角色抢话。

运行时循环

学员提问
  → 可选 close 短路（「我知道了/再见/回到课程」且非问句）
  → 导演 LLM 选工具（tool_choice=any，禁止可见散文）
  → 每条工具提议先过确定性规则再执行
  → call_agent → 子角色 LLM 出可见台词（+ 并行 TTS）
  → 直至 cue_user | close_session | 达上限 fallback cue
  → 前端按序出字播报

状态机（前端可观察）

状态进入离开UI
idle初始 / 终态后发送可输入、可点推荐
thinking请求发出首条台词 / 错误 / 停止讲师思考占位；发送→停止
streaming有台词播报完 / 停止 / 错误出字+语音；历史播放/重生置灰
terminal_cuecue_user新提问可继续问
terminal_closeclose_session新提问结束分隔；主课不停
error失败/超时重试/新问黄错误卡

4.1 工具契约

工具参数语义约束
call_agent agent_id, instruction 指定名单内角色说一句可见台词 计入 turn 预算；instruction 短任务一句
cue_user prompt? 交回学员继续问 与 close 互斥；讲师须已实质答过（规则兜底）
close_session end_reason 结束本旁路问答（不关整课） 白名单：user_done | user_goodbye | back_to_lesson；close 前须有可见台词

导演不得输出学员可见文本。若模型生成散文，丢弃内容，只认 tool_calls。

4.2 硬规则与确定性兜底

导演 LLM 只「提议」；执行前必须过规则。规则失败记入 director_trace（调试）/ errors，不把非法发言给学员。

#规则兜底
R1角色归一：仅 1 teacher + students丢弃其他 type；多讲师只留第一；无讲师注入默认
R2首条实质台词必须是讲师同学首 call → 改派讲师
R3同学禁止连说换未发言同学或跳过；讲师可续讲
R4只能 call 名单内 id未知 id 跳过并记 error
R5call_agent ≤ N（默认 3，硬顶 6）超限丢弃后续 call
R6同学发言后须留名额给讲师回应已无余量则 skip_student
R7不得以同学收尾终态前强制讲师回应追问（必要时 over_budget +1）
R8仅最后一条讲师台词可向学员提问中途讲师台词剥末尾问句；指令注入 mid/final 标记
R9cue / close 互斥同批只取第一个终态工具
R10裸 close / 裸 cue / 无工具先补讲师可见台词再终态；无工具 → 讲师直答 + cue
R11close 短路短句「我知道了/明白了/再见/回到课程」且无 ?/吗/呢、无否定 → 跳过导演，讲师收束 + close
R12auto-terminate同批已 call 但忘终态 → 直接 cue，省第二轮导演

Close 短路样例

  • 命中 close：我知道了 / 明白了，谢谢 / 好的再见 / 回到课程吧
  • 不命中（交导演）：这样写可以了吗 / 可以了？ / 懂了吗 / 我还是不明白

4.3 Prompt / 人设 / 生成

导演 system（要点）

  • 只通过工具决策；不写可见台词。
  • 讲师首答；同学只追问/补充；同同学不连说。
  • 优先 1～2 个 agent；同批打出 call + 终态，避免第二轮导演。
  • 同学追问后必须再 call 讲师再终态。

子角色

  • system = 归一后人设（≤1600 字）+「只输出本角色台词」约束。
  • user = 学员问题 + 短 instruction + 同伴摘要（预览截断，禁止灌全量历史）。
  • 讲师：中途指令带「不要向学员提问」；最后一句才允许一句反问。
  • 长度：讲师 ≤4 句；同学 1～2 句；中文口语。

人设五节（润色 / 生成强制）

# Personality
# Environment
# Goal
# Guardrails
# Tone

音色白名单

沉稳男声 | 低沉男声 | 活泼男声 | 亲和女声 | 清亮女声 | 平稳女声

添加伙伴输出字段

4.4 接口契约（实验室已实现，生产对齐行为）

方法路径用途关键字段
POST/session/new开会话agents?, max_agent_turns? → thread_id
POST/chat一轮问答thread_id, message, agents?, turn_id, max_agent_turns, include_trace?
POST/turn/rollback停止/重生/重试thread_id, turn_id, shown=null|[]|[{agent_id,name,text}]
POST/tts合成text, voice, role_type → audio_base64
POST/prompt/generate人设润色/生成name, role_type, seed, course_hint
POST/prompt/normalize结构归一prompt, role_type, name
POST/role/companion添加伙伴course_hint, exclude_names[] → role
GET/health探活tts / checkpoint 状态

/turn/rollback

  • shown=null：整轮撤回（重新生成 / 重试）。
  • shown=[]：思考中停止 → 只留问题 + 停止注记。
  • shown=[…]：只保留已展示文字。
  • 仅允许回退最后一轮，否则 409。
  • 导演仍在跑：登记 deferred，跑完立即回退，返回 deferred: true。
  • 同 thread 多轮请求排队，保证停止回退先于下一问读历史。

/chat 响应（生产默认）

{
  "ok": true,
  "thread_id": "…",
  "replies": [{ "agent_id", "name", "type", "text" }],
  "terminal": "cue_user" | "close_session",
  "end_reason": "user_done" | null
  // director_trace 仅 include_trace=true
}

5. Eval / 护栏（防偏差）

目标：规则漂移、模型偷懒/抢话、人设结构残缺在 CI 或提测前被拦住。实验室真源：classroom_roles/tests/test_director_rules.py。

5.1 确定性单测（必须全绿，无网络）

用例 id脚本化导演输入期望
E-first-teacher先 call 同学speakers 首 = teacher；trace reroute
E-drop-assistant名单含 assistant助教不发言；error unknown 或 dropped_role
E-one-teacher两名讲师只保留第一位可被 call
E-inject-teacher仅同学名单注入默认讲师且其首答

5.2 在线抽查（有模型，提测必跑 ≥3 题）

题期望发言序（类型）额外断言
什么是点检？teacher → (student?) → teacher? 或 teacher 单答首=讲师；若有同学则不以同学收尾；仅末句可问学员
指标为锚怎么落到班组？同上call_agent 次数 ≤ 配置 N
我知道了teacher 短收束terminal=close_session；导演可 0 调
这样写可以了吗teacher 主导不误 close

通过标准：首答讲师 ≥90% 抽检；单轮平均 call ≤2.5（上限 3）；无导演可见气泡；无双终态。

5.3 人设 / 伙伴生成 Eval

  • 输出含且仅按序出现五节标题（允许 Environment 存在）。
  • /role/companion 的 type 永远是 student。
  • voice ∈ 白名单；name 不在 exclude_names；name 长度 ≤12。
  • seed/name/prompt 命中违规词表 → 拒绝或回落规则草稿（不把脏内容写入角色库）。
  • LLM 失败时规则回落仍返回可用 role（meta.draft_source=rules）。

5.4 产品行为回归（对照原型）

  • 回答中点历史播放不打断、无分隔线。
  • 停止后服务端只收到已显示半句（抓 /turn/rollback shown）。
  • 重新生成：先 rollback null 再 chat；用户问题不重复插入。
  • 思考中停止：deferred 或等价；草稿保留。

7. 验收清单（可测）

编排 P0

  • 任意实质问题，首条可见台词 type=teacher。
  • 请求带助教/第二讲师时，这些角色不发言。
  • 无「导演」可见气泡。
  • max_agent_turns=3 时 call 次数 ≤3（R7 合法 +1 须可审计）。
  • 终态仅为 cue 或 close 之一。
  • 裸 close 会先产出可见收束台词。
  • 「我知道了/明白了」→ close；课程主路径未结束。
  • cue 后同一旁路会话可继续提问。

配置 / UI P0–P1

  • 开关关闭：角色库不可见；学习页走默认角色。
  • 无法取消唯一讲师勾选。
  • 角色类型文案只有讲师/同学。
  • 侧栏品牌与设置入口均为「课堂伙伴」。
  • 回答中发送键为停止；停止插入正确分隔。
  • close 分隔不暴露 end_reason 代码。
  • 出字过程无「正在合成语音」条。

打断 P1

  • 回答中历史播放置灰且不打断。
  • 重新生成仅最后一轮；替换原答；服务端无旧答。
  • 思考中/出字中停止的上下文符合 §3 D07b。
  • 回答中回车不发送；停止后草稿仍在。
  • 非最后一轮 rollback → 409。

Eval

  • §5.1 单测全绿。
  • §5.2 至少 3 道在线题记录发言序与终态。
  • §5.3 伙伴生成抽检结构/白名单/type=student。
