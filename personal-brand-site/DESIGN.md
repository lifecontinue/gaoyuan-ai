### 1.2 排版与字体

- **展示标题**：**Playfair Display**（经典 Garalde 衬线体, 400/700, 含 italic）——端庄、有文学感
- **正文**：**Lora, Georgia, serif**（现代过渡型衬线体, 400/500/600, 含 italic）——可读性强的温暖衬线
- **手写点缀**：Flowmery（italic 花卉）、Homemade Apple（手写笔记风）——赋予「手作感」「亲切感」
- **字距**：全站 `letter-spacing: 0.05em~0.06em`，标题层级简单，整体「松呼吸」

### 1.3 布局与氛围

- 全屏 Three.js 3D 场景（WebGL 渲染的「数字孪生房间」），非传统版式
- 按钮圆角仅 **2~3px**——近似直角，克制、老派
- 描边 1.5px 细线，色彩控制极严且高度统一
- 按钮等 UI 元件带半透明纸底色 + 极淡阴影
- **核心氛围**：温暖、怀旧、故事感、手作 Journal、数字舒适空间

## 二、设计提炼：从「参考站」到「个人品牌站」

参考站是一个「数字孪生房间」，核心是 3D 叙事 + 纸本质感 + 文学温润。

**我们的站不需要复制一间 3D 房间**，而是提炼其**材质情绪**和**设计纪律**，注入 Bento Grid 的效率布局：

| 参考站特征 | 我们的转化方案 |
|-----------|--------------|
| 全屏 3D 房间 | 精选 3D 交互元素（卡片倾斜、视差、装饰粒子）+ 可选昼夜模式 |
| 纸本质感 | 全站继承：cream 底色、细金边、衬线体、低圆角 |
| 故事性叙事 | Bento 卡片错落——每个应用「一件作品」，整体构成「数字工坊」 |
| 手写体点缀 | 手写体仅用于签名/标题拉花，克制使用 |
| 昼夜切换 | 保留：日间纸本 / 夜间暖灯工坊双模式 |

**一句话风格定位**：**「数字工坊」——以纸本质感承载工具理性的个人品牌空间，温暖而精准。**

## 三、设计系统

### 3.1 色彩方案

| 变量名 | 日间模式 | 夜间模式 | 用途 |
|--------|---------|---------|------|
| `--bg-page` | `#F5ECD7` | `#1A1410` | 全站底色 |
| `--bg-surface` | `#FFF9F0` | `#2B2318` | 卡片底色 |
| `--bg-hover` | `#E8D5B5` | `#3C3226` | 悬停态 |
| `--border` | `#C4A882` | `#5C4430` | 描边 / 分割 |
| `--text-primary` | `#3D2B1F` | `#E8D5B5` | 主文字 |
| `--text-secondary` | `#5C3D2E` | `#C4A882` | 次文字 |
| `--text-muted` | `#8B7355` | `#8B7355` | 弱化文字 |
| `--accent-green` | `#7A8C68` | `#9BAF88` | 点缀 / 标签 |
| `--accent-amber` | `#D9A441` | `#FEC158` | 高亮 / 灯光色 |
| `--accent-coral` | `#C0693B` | `#D0855D` | 强调 / 链接悬停 |

### 3.2 字体系统

| 层级 | 字体栈 | 字重 | 用途 |
|------|--------|------|------|
| Display (英文) | `Playfair Display, serif` | 400 / 700 | 大标题 / Hero 名 |
| Display (中文) | `Noto Serif SC, serif` | 600 / 700 | 中文大标题 |
| Body (英文) | `Lora, Georgia, serif` | 400 / 500 | 正文 / 卡片描述 |
| Body (中文) | `Noto Serif SC, serif` | 400 / 500 | 中文正文 |
| Label | `DM Mono, Consolas, monospace` | 400 | 标签 / 技术元信息 / 编号 |
| Handwritten | `Homemade Apple, cursive` | 400 | 签名 / 标题点缀（约 1~2 处） |

**字号阶梯**：10 → 12 → 14(xs)/16(sm)/18(base)/22(md)/28(lg)/36(xl)/48(2xl)/64(3xl)（以 18px 为正文基准）

### 3.3 间距与圆角

- 基本单位：4px 栅格（spacing scale: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80）
- 卡片圆角：**3px**（继承参考站的克制）
- 按钮圆角：**3px**
- 大面板圆角：**6px**

### 3.4 动效策略

| 动效 | 技术 | 参数 |
|------|------|------|
| 卡片 3D 倾斜 | CSS `transform: perspective() rotateX() rotateY()` + mousemove | 最大倾斜 ±6°，回弹 spring |
| 卡片眩光 | `::after` 径向渐变随鼠标位移 | opacity 0~0.15 |
| 视差滚动 | IntersectionObserver + `translateY` | 系数 0.05~0.2，paint 仅在 transform |
| 渐显 | IntersectionObserver + `opacity` + `translateY(20px→0)` | threshold 0.2，stagger 80ms |
| 昼夜切换 | CSS 变量覆盖 + `document.documentElement` class toggle | transition 0.6s ease |
| 性能预算 | 仅使用 transform / opacity 动画；无 JS 主线程 layout | 遵循 `prefers-reduced-motion` |

### 4.2 Bento 网格策略

- 使用 CSS Grid `grid-template-areas` 定义桌面端布局
- 手动指定每张卡片面积（列跨 1~3，行跨 1~2），形成错落感
- 移动端退化为单列，保留「大卡片 → 小卡片」大小穿插节奏
- 新增应用只需：**在 `apps.js` 数组中加一条 + 指定 span**

## 五、技术架构

### 5.1 技术选型

| 层面 | 选择 | 理由 |
|------|------|------|
| 构建 | **零构建**（纯静态 HTML/CSS/JS） | 个人站点无需打包，可直接拖入服务器或托管 |
| CSS | 原生 CSS Variables + Grid + 分层文件 | tokens.css 统一变量，bento.css 管理布局 |
| JS | 原生 ES Modules | 无需框架 CDN，体积在 15KB 以内 |
| 3D | CSS 3D Transforms（无 WebGL） | 卡片 tilt 用 CSS transform，开销极低；全站无不必要的 GPU 压力 |
| 字体 | Google Fonts + `font-display: swap` | 衬线体约 80KB（woff2 subset），swap 保证不阻塞 |
| 图标 | 内联 SVG / Lucide | 小巧，颜色可变，无额外请求 |
| 分析 | 可选 百度统计 / GA 一行脚本 | —— |

### 5.2 数据驱动扩展

应用配置独立于代码：

```js
// assets/js/data/apps.js
export const apps = [
  {
    id: "app-1",
    name: "应用名称",
    desc: "一句话简介",
    icon: "assets/img/apps/app1-icon.svg",
    screenshot: "assets/img/apps/app1.png",
    url: "https://...",
    tags: ["工具", "AI"],
    span: { col: 2, row: 1 },  // Bento 网格跨度
    featured: false              // 是否在 Hero 区突出显示
  },
  // ... 新增只需添加一条
];
```

## 七、响应式策略

| 断点 | 宽度 | 布局变化 |
|------|------|---------|
| Desktop | ≥ 1024px | Bento Grid：3~4 列错落，卡片最大 span: col 3 / row 2 |
| Tablet | 768~1023px | Bento Grid：2 列，span 降级，部分大卡片缩减 |
| Mobile | < 768px | 单列，所有卡片 span 重置为 col:1, row:1；Hero 文字缩小；导航折叠为汉堡 |
| Touch | —— | 取消 3D tilt（触屏无 hover），卡片点按反馈用 scale |

## 八、待确认事项

1. **昼夜模式**：是否需要夜间模式切换？（参考站有，建议保留，提升「工坊」氛围感）
2. **三.js 装饰**：Hero 区可加一个小型 Three.js 装饰（旋转几何体/粒子），但会增加 ~150KB 体积。建议 **先不做**，用纯 CSS 装饰实现，保持极致轻量。
3. **应用数据**：目前有哪几款应用需要展示？名称、简介、图标/截图、链接各是什么？可在 `apps.js` 中直接填入。
4. **联系方式细节**：公众号名称、二维码文件、联系电话是否都已有素材？
5. **是否需要「作品长廊」详情区**：即每条应用单独一个大区块展示截图与说明，还是仅 Bento 卡片已足够？
