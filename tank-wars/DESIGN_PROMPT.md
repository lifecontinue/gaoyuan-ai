## 一、产品定位

| 维度 | 定义 |
|------|------|
| 目标用户 | 6-12 岁儿童 |
| 游戏类型 | 俯视射击 + 经营养成 |
| 核心玩法 | 驾驶坦克战斗，击败敌人收编为队友，攒钱升级装备 |
| 体验关键词 | 热血、爽快、收集、成长 |

## 二、视觉风格方向

### 2.1 风格定位

**「明亮卡通军事风」** — 军事题材但不暗黑，用明亮饱和的色彩表达战场，用圆润几何体表达坦克，用 emoji + 中文简化信息传达。

| 关键词 | 释义 |
|--------|------|
| 明亮 | 天空亮蓝、草地鲜绿，阴影柔和不压抑 |
| 卡通 | 坦克圆润、建筑带表情、粒子多彩 |
| 军事 | 装甲纹理、迷彩元素、军事图标 |
| 热血 | 击杀粒子爆发、金币飘字、震动反馈 |

### 2.2 参考锚点

- 《蛋仔派对》的 Q 版圆润造型
- 《坦克大决战》的经典俯视射击感
- 《植物大战僵尸》的暖色明亮调
- 《元气骑士》的像素粒子特效

## 四、坦克造型规范

### 4.1 结构分解

```
        炮管 (barrel)
        ║
   ┌────╨────┐
   │  炮塔    │  ← 圆形，居中
   │ (turret) │
   ├──────────┤
   │  车体    │  ← 矩形主体
   │ (body)   │
   │  ══════  │  ← 底部阴影带（8px）
   │  履带    │  ← 左右各 6px
   │ (treads) │
   └──────────┘
        ▓▓▓▓      ← 底部投影（6px 偏移）
```

### 4.2 类型差异

| 类型 | 车体 | 炮塔 | 炮管 | 特色 |
|------|------|------|------|------|
| 均衡 | 44×44 标准 | 12px 标准 | 20px 标准 | 中庸万能 |
| 重装 | 52×52 宽大 | 15px 厚重 | 28px 长炮管 | 移动堡垒 |
| 极速 | 36×36 窄长 | 9px 紧凑 | 14px 短管 | 尾部红色排气管+拖尾 |
| 狙击 | 36×36 扁长 | 8px 小型 | 32px 超长狙击管 | 翠绿伪装色 |
| 蜂群 | 28×28 迷你 | 6px 微型 | 10px 迷你管 | 金色小翅膀 |

### 4.3 渲染参数

| 参数 | 值 |
|------|-----|
| 车体阴影偏移 | 右下 6px |
| 履带宽度 | 6px，从车体左右各向外 5px |
| 炮塔颜色 | 车体色暗 22 阶 |
| 炮管宽度 | 8px |
| 车体底部阴影带 | 8px，颜色=车体色暗 22 阶 |
| HP 条 | 40×6px，圆角 3px，头顶上方 14px |
| 伤害闪白 | 每 4 帧中 2 帧闪白，持续 6 帧 |

## 七、交互反馈标准

| 操作 | 反馈（≤200ms） | 效果 |
|------|----------------|------|
| 子弹命中敌人 | 伤害闪白 + 红粒子 3个 | 2帧/周期闪白，粒子 25帧 |

| 玩家死亡 | 大量粒子 25+15个 + 震动 10px | 烟花式爆发 |
| 护盾受击 | 蓝粒子 6个 + 光圈闪烁 | 衰减光圈 |
| 技能释放 | Toast 通知 + 粒子/音效 | 顶部居中弹出 |

| 蜂群移动 | 尾部金色拖尾 | 2个圆点，alpha 0.6 |

### 9.2 敌人转盟友

- 仅限均衡/重装/极速三种基础类型
- 上限 3 个，满员后击杀只给金币不转化
- 转盟友后：HP 82%、伤害 88%、速度 96%
- 无敌人时：跟随玩家后方环形编队
